## Google Search Console: owner setup

1. Open https://search.google.com/search-console and add the exact documentation URL
   as a URL-prefix property.
2. Verify ownership using a supported method. If HTML-file verification is offered,
   place the exact Google-provided file in the site's static output and republish.
   Do not invent a verification token or claim verification before Google confirms it.
3. Submit `https://openmausbot-python-mcp-bridge.copperpearl.chatgpt.site/sitemap.xml`.
4. Inspect the home page and request indexing if eligible. Monitor indexing and
   performance rather than assuming that submission guarantees inclusion.

Search Console setup requires the owner's Google account and is not completed by
publishing this repository. A robots.txt at a path on github.com cannot control
GitHub's crawler policy; the site's own robots.txt applies only to its host.
